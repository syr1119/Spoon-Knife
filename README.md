### 你好！

这个仓库旨在提供一个*克隆*GitHub 上仓库的示例。

创建一个*分支*是创建另一个项目的所有者的个人副本。分支起到了原始仓库和个人副本之间的桥梁作用。你可以提交*拉取请求*，通过提供你的更改来帮助改进其他人的项目。分支是GitHub 社区编码的核心。

在克隆这个仓库后，你可以对项目进行一些修改，并提交[一个拉取请求](https://github.com/octocat/Spoon-Knife/pulls) 作为练习。

关于如何克隆仓库的更多信息，[请查看我们的指南，“克隆项目”](http://guides.github.com/overviews/forking/)。谢谢！:sparkling_heart:
